## 鼠标操作

### mouse-move

移动鼠标到指定位置。

```bash
# 移动到屏幕坐标
macos-computer-use mouse-move --x 500 --y 300

# 移动到元素中心
macos-computer-use mouse-move --app Safari --target "地址栏"

# 相对移动
macos-computer-use mouse-move --dx 100 --dy 50
```

### left-click

左键点击。

```bash
# 点击坐标
macos-computer-use left-click --x 500 --y 300

# 点击元素
macos-computer-use left-click --app Safari --target "刷新按钮"
```

### right-click

右键点击。

```bash
macos-computer-use right-click --app Finder --target "文件1.txt"
```

### double-click

双击。

```bash
macos-computer-use double-click --app Finder --target "文档文件夹"
```

### middle-click

中键点击（常用于关闭标签页）。

```bash
macos-computer-use middle-click --app Safari --target "标签页标题"
```

### drag

拖拽操作。支持从当前鼠标位置或指定起点拖拽到目标坐标。

```bash
# 从当前鼠标位置拖拽到目标坐标
macos-computer-use drag --to-x 500 --to-y 600

# 从指定起点拖拽到目标坐标
macos-computer-use drag --start-x 100 --start-y 200 --to-x 500 --to-y 600

# 从当前位置拖拽到元素（先移动鼠标到元素）
macos-computer-use mouse-move --app Safari --target "上传区域"
macos-computer-use drag --to-x 500 --to-y 600
```

### scroll

滚动。

```bash
# 在应用内滚动
macos-computer-use scroll --app Safari --target "页面内容" --delta-y -500

# 在坐标处滚动
macos-computer-use scroll --x 500 --y 500 --delta-y -300
```

### mouse-hover

鼠标悬停。

```bash
# 悬停在元素上
macos-computer-use mouse-hover --app Safari --target "帮助图标" --duration 2

# 悬停在坐标上
macos-computer-use mouse-hover --x 500 --y 300 --duration 1
```

#### 系统对话框（Sheet）支持

使用 `--sheet` 参数点击系统对话框（如文件选择器 NSOpenPanel）内的元素：

```bash
# 点击文件选择器中的「打开」按钮
macos-computer-use element-click --app TextEdit --sheet --title "打开"

# 点击文件选择器中的「取消」按钮
macos-computer-use element-click --app TextEdit --sheet --title "取消"

# 点击文件选择器中的「前往文件夹」按钮
macos-computer-use element-click --app TextEdit --sheet --title "前往文件夹"

# 结合 element-list 查找并点击
macos-computer-use element-list --app TextEdit --sheet --type button
macos-computer-use element-click --app TextEdit --sheet --title "打开" --role button
```

**⚠️ 限制说明：** 同 `element-list --sheet`，仅支持传统 AppKit 应用的 Sheet 模式，不支持现代 SwiftUI 应用的独立进程文件选择器。详见 `element-list` 的「系统对话框（Sheet）支持」章节。

### element-info

获取元素信息。

```bash

```

### element-list

列出所有元素。

```bash
macos-computer-use element-list --app Safari
macos-computer-use element-list --app Safari --type button
```

#### 系统对话框（Sheet）支持

使用 `--sheet` 参数列出系统对话框（如文件选择器 NSOpenPanel）内的元素：

```bash
# 列出文件选择器中的所有元素
macos-computer-use element-list --app TextEdit --sheet

# 列出文件选择器中的按钮
macos-computer-use element-list --app TextEdit --sheet --type button

# 查找「前往文件夹」按钮
macos-computer-use element-list --app TextEdit --sheet | grep "前往文件夹"
```

**⚠️ `--sheet` 参数限制说明：**

| 应用场景 | 是否支持 | 说明 |
|---------|---------|------|
| 传统 AppKit 应用（如 TextEdit） | ✅ 支持 | 文件选择器作为 Sheet 附加到窗口 |
| 现代 SwiftUI 应用（如 LyricVoice） | ❌ 不支持 | 文件选择器运行在独立进程 |
| 系统级权限对话框 | ❌ 不支持 | 需要特殊权限 |

**技术原理：**
- `--sheet` 通过 `kAXSheetAttribute` 访问窗口的 Sheet 元素
- 仅当系统对话框作为 Sheet 附加到应用窗口时才有效
- 现代 macOS 文件选择器通常运行在 "Open and Save Panel Service" 独立进程中

**替代方案（检测/关闭文件选择器）：**
```bash
# 检测文件选择器是否打开
macos-computer-use window-list --json | grep '"打开"'

# 关闭文件选择器（发送 Escape 键）
macos-computer-use key --key escape
```

## 文件系统

### file-read

读取文件内容。

```bash
# 读取文本文件
macos-computer-use file-read ~/Documents/note.txt

# 以 base64 编码输出（适用于二进制文件）
macos-computer-use file-read ~/Pictures/image.png --base64

# JSON 输出
macos-computer-use file-read ~/config.json --json
```

### file-write

写入文件内容。

```bash
# 写入文本
macos-computer-use file-write ~/output.txt --text "Hello, World!"

# 追加模式
macos-computer-use file-write ~/log.txt --text "New log entry" --append

# 从 base64 解码写入
macos-computer-use file-write ~/image.png --base64 "iVBORw0KGgo..."

# 自动创建父目录
macos-computer-use file-write ~/new/dir/file.txt --text "content" --create-dirs
```

### file-exists

检查文件或目录是否存在。

```bash
# 检查文件是否存在
macos-computer-use file-exists ~/Documents/report.pdf

# 检查目录是否存在
macos-computer-use file-exists ~/Downloads --directory

# 反向断言（断言不存在）
macos-computer-use file-exists ~/temp.txt --not-exists

# JSON 输出
macos-computer-use file-exists ~/data.json --json
```

## 脚本执行

### run-script

执行增强型 JSON 脚本，支持变量、条件和循环。

```bash
# 执行脚本
macos-computer-use run-script --file workflow.json

# 仅验证语法
macos-computer-use run-script --file workflow.json --dry-run

# JSON 输出执行结果
macos-computer-use run-script --file workflow.json --json
```

脚本格式示例：
```json
[
  { "id": "set-url", "action": "set-variable", "params": { "name": "url", "value": "https://example.com" } },
  { "id": "navigate", "action": "app-launch", "params": { "app": "Safari" }, "if": { "op": "exists", "left": "{{url}}" } },
  { "id": "wait", "action": "sleep", "params": { "ms": "2000" }, "retry": 3, "retryInterval": 1000 },
  { "id": "foreach-test", "action": "type", "params": { "text": "{{item}}" }, "forEach": "item", "in": "hello,world,test" }
]
```

### dialog-open-file

在系统文件选择器中自动选择文件（使用「前往文件夹」功能）。

适用于现代 macOS 应用的文件选择器（包括 SwiftUI 应用），通过 Command+Shift+G 快捷键打开「前往文件夹」对话框，输入文件路径后自动选择。

```bash
# 在 LyricVoice 的文件选择器中选择指定文件
macos-computer-use dialog-open-file --app "LyricVoice" --path "/Users/wangmin/traeProjects/LyricVoice/test/audio/chinese_10s.wav"

# JSON 输出
macos-computer-use dialog-open-file --app "LyricVoice" --path "/path/to/file.wav" --json
```

**⚠️ 重要前提条件：**

使用此命令前，**必须确保文件选择器已经打开**。不同应用打开文件选择器的方式不同：

| 应用类型 | 打开文件选择器的方式 | 示例 |
|---------|---------------------|------|
| 菜单点击 | 点击「文件」→「打开」 | `macos-computer-use menu-click "文件,打开" --app "LyricVoice"` |
| 按钮点击 | 点击界面上的「添加文件」按钮 | `macos-computer-use element-click --app "LyricVoice" --identifier "add-audio-button"` |
| 快捷键 | Command+O | `macos-computer-use hotkey --keys "command+o"` |

**完整使用流程：**

```bash
# 步骤 1: 先打开文件选择器（以按钮点击为例）
macos-computer-use element-click --app "LyricVoice" --identifier "add-audio-button"
sleep 1

# 步骤 2: 确认文件选择器已打开（可选，用于调试）
macos-computer-use window-list --json | grep '"打开"'

# 步骤 3: 使用 dialog-open-file 选择文件
macos-computer-use dialog-open-file \
  --app "LyricVoice" \
  --path "/Users/wangmin/traeProjects/LyricVoice/test/audio/chinese_10s.wav"
```

**工作原理：**
1. 激活目标应用
2. 发送 Command+Shift+G 打开「前往文件夹」对话框
3. 输入文件完整路径
4. 按回车确认路径
5. 再次按回车选择文件

**注意事项：**
- **必须先打开文件选择器**，否则 Command+Shift+G 会在应用中执行其他功能
- 文件路径必须是完整绝对路径
- 文件必须存在，否则文件选择器会显示警告
- 如果文件选择器未打开，命令会失败或产生意外行为

### dialog-confirm

确认文件选择器的选择（相当于点击「打开」按钮）。

发送回车键来确认当前选中的文件或文件夹。

```bash
# 确认选择（相当于点击「打开」按钮）
macos-computer-use dialog-confirm

# 指定应用后确认
macos-computer-use dialog-confirm --app "LyricVoice"

# JSON 输出
macos-computer-use dialog-confirm --json
```

**使用场景：**
- 使用 `dialog-open-file` 选择文件后，需要单独确认时
- 在文件选择器中手动选择文件后，需要点击「打开」按钮

**完整流程示例：**
```bash
# 1. 打开文件选择器
macos-computer-use element-click --app "LyricVoice" --identifier "add-audio-button"
sleep 1

# 2. 选择文件路径
macos-computer-use dialog-open-file --app "LyricVoice" --path "/path/to/file.wav"
sleep 0.5

# 3. 确认选择（如果 dialog-open-file 的自动确认未生效）
macos-computer-use dialog-confirm --app "LyricVoice"
```

### dialog-cancel

取消或关闭文件选择器（相当于点击「取消」按钮或按 Escape 键）。

```bash
# 关闭文件选择器
macos-computer-use dialog-cancel

# 指定应用后关闭
macos-computer-use dialog-cancel --app "LyricVoice"

# JSON 输出
macos-computer-use dialog-cancel --json
```

**使用场景：**
- 取消文件选择操作
- 关闭已打开的文件选择器
- 在自动化流程中需要放弃选择时

**完整流程示例：**
```bash
# 1. 打开文件选择器
macos-computer-use element-click --app "LyricVoice" --identifier "add-audio-button"
sleep 1

# 2. 决定取消选择
macos-computer-use dialog-cancel --app "LyricVoice"
```
