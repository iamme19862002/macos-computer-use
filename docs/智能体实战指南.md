## 核心价值

### 为什么 AI Agent 需要这个工具？

| 传统方案 | macos-computer-use |
|----------|-------------------|
| 调用远程 API（消耗 Token） | 本地执行（零 Token） |
| 只能获取文本（无法操作 UI） | 直接控制鼠标、键盘、应用 |
| 无法读写本地文件 | 完整的文件系统操作 |
| 无法感知当前状态 | 前台应用/焦点元素检测 |
| 无法验证操作结果 | 断言验证（OCR + 元素检查） |
| 单步执行无容错 | 重试、等待、条件判断 |

### Agent 能力增强

```
Before: Agent 只能"建议"用户操作
After:  Agent 直接"执行"并"验证"操作
```

### 模式 2：自动化测试执行器

```python
def run_test_suite(test_cases):
    results = []
    for case in test_cases:
        execute(f"macos-computer-use test-start --name '{case.name}' --id '{case.id}'")
        
        for step in case.steps:
            execute(f"macos-computer-use step --name '{step.name}'")
            try:
                output = execute(step.command)
                step.result = "PASS"
            except:
                execute("macos-computer-use screenshot --filename error.png")
                step.result = "FAIL"
                break
        
        result = "PASS" if all(s.result == "PASS" for s in case.steps) else "FAIL"
        execute(f"macos-computer-use test-end --result {result}")
        results.append({"case": case.name, "result": result})
    
    return results
```

```python
#!/usr/bin/env python3
# Python 封装：文件选择器自动化

from macos_computer_use import MacOSComputerUse
import json

mcu = MacOSComputerUse()

def select_file_in_dialog(app_name: str, button_title: str, file_path: str) -> bool:
    """
    在文件选择器中自动选择文件
    
    Args:
        app_name: 目标应用名称
        button_title: 打开文件选择器的按钮标题
        file_path: 要选择的文件完整路径
    
    Returns:
        bool: 是否成功
    """
    # 使用 dialog-open-file 一键完成
    result = mcu._execute(
        f'dialog-open-file --app "{app_name}" --button "{button_title}" --path "{file_path}" --json'
    )
    
    return result.get("success", False)

def batch_select_files(app_name: str, button_title: str, file_paths: list) -> dict:
    """
    批量选择多个文件
    
    Args:
        app_name: 目标应用名称
        button_title: 打开文件选择器的按钮标题
        file_paths: 文件路径列表
    
    Returns:
        dict: 每个文件的选择结果
    """
    results = {}
    
    for file_path in file_paths:
        file_name = file_path.split("/")[-1]
        print(f"正在选择文件: {file_name}")
        
        success = select_file_in_dialog(app_name, button_title, file_path)
        results[file_name] = success
        
        if success:
            print(f"✓ {file_name} 选择成功")
        else:
            print(f"✗ {file_name} 选择失败")
        
        # 等待一下再处理下一个
        mcu.sleep(1)
    
    return results

# 使用示例
if __name__ == "__main__":
    # 单文件选择
    success = select_file_in_dialog(
        app_name="LyricVoice",
        button_title="添加文件",
        file_path="/Users/iamme19862002/traeProjects/LyricVoice/test/audio/chinese_10s.wav"
    )
    print(f"文件选择结果: {'成功' if success else '失败'}")
    
    # 批量文件选择
    files = [
        "/Users/iamme19862002/traeProjects/LyricVoice/test/audio/chinese_10s.wav",
        "/Users/iamme19862002/traeProjects/LyricVoice/test/audio/chinese_1min.mp3",
        "/Users/iamme19862002/traeProjects/LyricVoice/test/audio/english_30s.wav"
    ]
    
    results = batch_select_files("LyricVoice", "添加文件", files)
    print(f"\n批量选择结果: {json.dumps(results, indent=2)}")
```

    def _execute(self, command: str) -> Dict[str, Any]:
        """执行命令并解析结果"""
        full_command = f"macos-computer-use {command}"
        if self.json_output and "--json" not in command:
            full_command += " --json"
        
        result = subprocess.run(
            full_command.split(),
            capture_output=True,
            text=True

            output = json.loads(result.stdout)
            output["exit_code"] = result.returncode
            return output

## 故障排除

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 元素找不到 | 应用未激活 | 先执行 `app-activate` |
| 操作没反应 | 焦点在其他窗口 | 确保目标应用在前台 |
| 断言超时 | 页面未加载完 | 增加超时时间或先 `sleep` |
| OCR 识别率低 | 分辨率或字体问题 | 放大窗口或调整对比度 |
| 快捷键无效 | 应用未聚焦 | 使用 `app-activate` 后再发送 |

function assert_pixel_color() {
    local x=$1 y=$2 expected=$3
    result=$(macos-computer-use pixel-color --x $x --y $y --json)
    if echo "$result" | grep -q "\"hex\":\"$expected\""; then
        echo "✓ 像素颜色匹配: $expected"
        return 0
    else
        echo "✗ 像素颜色不匹配，期望: $expected"

    fi
